Configurar La Porra

Solo para el administrador

1. Crea un token de GitHub

  1. Ve a GitHub → Fine-grained tokens → Generate new token.
  2. Nombre: la-porra. Caducidad: la máxima que te deje (p. ej. 1 año).
  3. Repository access: Only select repositories → la-porra.
  4. Permissions → Repository permissions → Contents: Read and write. Nada más.
  5. Genera el token y cópialo (empieza por github_pat_).

2. Cífralo con la contraseña familiar

El token nunca se publica en claro: se guarda cifrado (AES-256) y solo quien sepa la contraseña familiar puede usarlo. No distingue mayúsculas/minúsculas.

3. Pega esto en js/config.js

Sustituye la línea encryptedToken: null, por:

Puedes editarlo directamente en GitHub (abre js/config.js → ✏️ → pega → Commit changes). En un minuto la web estará lista.
